# Hsoj.is-a.dev
## [hsoj.is-a.dev](https://hsoj-is-a-dev.pages.dev/)
Welcome! This is the repository for my personal site.

## Tech Stack
- Frontend Framework: Sveltekit
- Styling: Tailwind
- Deployment: Cloudflare Pages

I have used SvelteKit before, so I decided to use it again for this project, especially for its page routing. As always, the developer experience was a breeze, and pairing it with Tailwind made the site a joy to create. As for the deployment, I had no prior experience using Cloudflare, so I thought, "Why not try it?"
